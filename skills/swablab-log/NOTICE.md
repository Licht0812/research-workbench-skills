SWABLAB Log is an original skill and standard-library recorder created from the SWABLAB training-run requirements on 2026-10-07. It manages raw logs, step-level metrics, native checkpoint paths, Slurm associations, and static information collected by SwanLab.

SwanLab integration examples and static-file access were checked against the official v0.10.1 API and probe format. They are technical references, not imported skill instructions. This package does not bundle training frameworks, model weights, datasets, or tracker services.
