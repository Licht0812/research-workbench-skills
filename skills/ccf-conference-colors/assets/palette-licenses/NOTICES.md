This product includes color specifications and designs developed by Cynthia Brewer (http://colorbrewer.org/).

For viridisLite, the standard R MIT template was completed with the separately supplied copyright entry. For Tol, standard BSD clauses were completed with the copyright from the author's script; this combined file is assembled here, not represented as an original full author-supplied license file. The six included Tol schemes are bright, high_contrast, vibrant, muted, medium_contrast, and light. Web-only pale and dark are excluded.

Scientific colour maps attribution: Fabio Crameri (2023), Scientific colour maps 8.0.1, [doi:10.5281/zenodo.8409685](https://doi.org/10.5281/zenodo.8409685). The author archive's extracted MIT text is retained; palette tables have the upstream 8-bit sRGB quantization, and no new resampling is stored.

The interactive gallery and previews display these same licensed tables. Preserve this notice and the corresponding license files when copying a gallery or palette dataset. Source reports about color-vision behavior are descriptive evidence, not a universal guarantee for a finished figure.
