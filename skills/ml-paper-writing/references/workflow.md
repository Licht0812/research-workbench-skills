# ML Paper Writing: decisions and validation

## Decision points

- A local polish does not authorize redesigning the method, expanding experiments, or rewriting unrelated sections.

- For a full paper, use the actual contribution and venue constraints to allocate space. Verify current official venue rules rather than copying fixed page counts.

- If CCFA or another manuscript workflow already owns the document, preserve that owner unless the user selects this workflow; no sibling skill is required when used alone.

## Verify the requested change

- Reported numbers, baselines, datasets, and conclusion strength match the supplied evidence.

- Citations resolve to real sources and support the associated claims; unresolved references remain explicitly unresolved.

- The requested artifact is complete in its source format, with specific missing evidence identified when necessary.

Run only checks relevant to the change. Distinguish a proposed configuration, a successful smoke check, and a completed scientific evaluation. Do not turn an upstream benchmark or example into a measured result of the current task.
